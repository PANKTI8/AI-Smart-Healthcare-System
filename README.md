# AI Smart Healthcare Disease Predictor

An AI-based healthcare web application that predicts diseases using Machine Learning models.

## Features
- Diabetes Prediction
- Headache Type Prediction
- Symptom-based Disease Detection
- Machine Learning Models
- Web Interface using HTML, CSS, JavaScript
- Flask Backend API

## Technologies Used
- Python
- Flask
- Scikit-learn
- HTML
- CSS
- JavaScript
- Machine Learning

## How to Run the Project

1. Install dependencies
pip install -r requirements.txt

2. Run backend
cd backend
python app.py

3. Open frontend
Open index.html using Live Server

## Output
The system predicts disease risk using trained AI models.
